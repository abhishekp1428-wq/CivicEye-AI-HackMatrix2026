# 🚀 CivicEyeAI

CivicEyeAI is an AI-powered civic complaint management system built with FastAPI.

## ✨ Features

- User Authentication
- Image Upload
- AI Complaint Analysis
- Location Detection
- Complaint Generation
- Dashboard
- Department Classification

## 🛠️ Tech Stack

- Python
- FastAPI
- SQLAlchemy
- MySQL
- HTML
- CSS
- JavaScript
